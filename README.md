# E-commerce Sales & Customer Analytics using MySQL

## Project Overview

This project analyzes a sample e-commerce database using MySQL to explore product performance, sales revenue, customer purchasing behavior, and order trends.

The project was built as a hands-on learning exercise to develop practical SQL skills and understand how data analysis can support business decisions.

## Objectives

- Analyze product and category performance.
- Calculate revenue across products, categories, and orders.
- Identify high-value customers and understand customer spending.
- Examine order statuses and payment methods.
- Practice SQL aggregation, joins, filtering, sorting, and subqueries.

## Tech Stack

- **Database:** MySQL
- **Environment:** VS Code
- **Version Control:** Git and GitHub
- **Analysis:** SQL

## Database Schema

The database, `ecommerce_analytics`, contains five related tables:

| Table | Description |
|---|---|
| `Customer` | Customer details, including name and city |
| `Categories` | Product category information |
| `Product` | Product names, prices, and category IDs |
| `Orders` | Order dates, customers, payment methods, and statuses |
| `Order_item` | Products purchased, quantities, and unit prices per order |

These tables are connected through primary keys and foreign keys, allowing data to be analyzed across customers, orders, products, and categories.

## Analysis Questions

The project includes 20+ SQL analysis questions covering:

### 1. Customer Analysis
- Count the total number of customers.
- Find customers from a particular city.
- Calculate customer spending.
- Identify customers who placed multiple orders.
- Find the highest-spending customers.
- Identify customers spending below the average customer spending.

### 2. Product Analysis
- Find the highest-priced product.
- Calculate the average product price.
- Count products in each category.
- Calculate the quantity sold per product.
- Identify the top-selling products.
- Calculate revenue generated by each product.
- Find the top products by revenue.

### 3. Category Analysis
- Calculate the quantity sold in each category.
- Calculate revenue generated by each category.
- Identify the highest-revenue category.

### 4. Order Analysis
- Calculate the average order value.
- Identify the highest-value order.
- Find orders containing multiple order items.
- Identify the customer associated with the highest-value order.

### 5. Payment and Order Status Analysis
- Calculate order value by payment method.
- Analyze order value across different order statuses.

## SQL Concepts Practiced

- `SELECT` and `WHERE`
- Aggregate functions: `SUM()`, `AVG()`, `COUNT()`, `MAX()`
- `GROUP BY` and `HAVING`
- `ORDER BY` and `LIMIT`
- Aliases and calculated columns
- `INNER JOIN` across multiple tables
- Subqueries and nested aggregations
- Revenue calculations
- Customer-level, product-level, category-level, and order-level analysis

## Key Findings

Some of the findings from the current dataset include:

- The **Electronics** category generated the highest total product revenue.
- The **Laptop** was the highest-revenue product.
- **Ujjawal** was the highest-spending customer in the dataset.
- **UPI** generated the highest order value among the payment methods analyzed.
- The dataset contains completed, pending, cancelled, and returned orders.

*Note: Revenue grouped by order status represents the value associated with each status; it should not automatically be interpreted as realized sales revenue.*

## How to Run

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd ecommerce-analytics
```

### 2. Create the database and tables

Run the SQL setup script using MySQL:

```bash
mysql -u root -p < tables.sql
```

### 3. Load the sample data

```bash
mysql -u root -p ecommerce_analytics < data.sql
```

### 4. Run the analysis

```bash
mysql -u root -p ecommerce_analytics < analysis.sql
```

Make sure the database is created by the setup script and that the SQL files use the correct database name.
